# Second Chance · 温故而知新

拍作业 · 勾选本次重练的题 · 预览并打印

一个自用的错题采集工具：拍下孩子批改过的作业页，自动放平、按题目之间的空隙切成错题，  
勾选要重练的题，按需遮住答案，即可生成 A4 练习卷。

## 启动

```bash
pip install -r requirements.txt
python -m uvicorn app:app --port 8010
```

浏览器打开 <http://localhost:8010/>。

> 端口用 8010 而不是 8000：本机 8000 可能被梵想云（FanxiangCloud）自带的 nginx 占用。
>
> 首次启动会自动建表（`questions.db`）并给旧库补齐缺失字段，无需手动迁移。

## 手机拍照上传

服务以 `--host 0.0.0.0` 启动（`start-server.bat` 已默认），手机连上同一个 Wi-Fi，  
浏览器访问 `http://<电脑局域网IP>:8010` 即可拍照上传，电脑上 `ipconfig` 可查本机 IP。  
首次开放需放行防火墙 8010 端口（管理员运行）：

```bat
netsh advfirewall firewall add rule name="SecondChance-8010" dir=in action=allow protocol=TCP localport=8010
```

> 注意：同一 Wi-Fi 下的所有设备都能访问本服务（未加口令），家庭网络请自行评估。

## 高拍仪

成者 / 极匠等高拍仪是标准 USB 摄像头（UVC），浏览器直接取流，**不需要装厂商客户端或 SDK**。

1. 高拍仪插在跑服务的那台电脑上，用 <http://localhost:8010> 打开（浏览器只在 localhost / HTTPS 下允许调摄像头，
   所以用局域网 IP 打开时不会出现这个按钮）。
2. 点 **用高拍仪拍**，首次使用允许浏览器访问摄像头。会自动选中名字里带 CZUR 的设备；
   带副摄像头的型号如果选成了副摄，在下拉框里换成主摄即可，下次会记住。
3. 作业铺在黑色软垫上，每换一页点 **拍这一页**（或按空格），拍完点 **完成**。
   拍下的页在后台逐页切题，可以一直往下拍。画面方向不对时点 **旋转画面**，角度会记住。

画面按设备最高分辨率取流，存图时长边缩到 3600px（A4 约 300dpi），切题和打印都够用。
成者客户端开着时会占住摄像头，用之前先关掉它。

## 使用流程

### 1. 拍作业

点 **拍照 / 选择照片**，再点 **用这张照片**。系统尝试摆正页面并按题间空隙切题，结果显示在“本次重练”。它不会判断每一道题是否做错，需要你勾选要重练的题。

### 2. 选题，按需修正

勾选卡片上的 **加入本次重练**。也可以点 **从以前的题里选**，把旧题加入这一卷。

每道题的 **修正 / 备注** 中提供遮答案、调整整页切题、知识点、备注和删除。知识点与备注均可不填。遮挡只影响打印，不修改原图。

调整切题时，拖动分割线移动边界，点空白处加线，点下方标签删线；照片歪了可以手动摆正。重新切题或摆正后，需要重新勾选这一页的题，其他页的选择保留。

### 3. 预览并打印

底部显示已选题数。点 **预览并打印**，只生成本次勾选的题，等图片加载完成后即可打印。未标知识点的题也能正常出卷。

同一浏览器标签页刷新后会恢复本次选题。点 **开始新一卷** 清空本次选择，已保存的题仍在题库里。

## 设计取舍

**为什么不自动识别红叉？** 试过，红叉数量 ≠ 题目数量。一道题可能有多个答案、多个红叉；

老师还会用圈叉、划波浪线、在旁边写批注。9 月连续三次"加了 AI / 红叉自动切题又删掉"就是撞在这上面。

**现在的做法**：机器从两个信号猜题目边界。一是"题目之间的空白带"（比红叉可靠得多）；二是 OCR 找**顶格的题号行**（"5." "三、"）——题号新起一行的地方必然是题界，行距宽窄、红笔、手写挤占空隙都影响不到它。两个信号取并集，OCR 失败时自动退回纯几何。

猜错了拖一下就行。猜漏一道题 = 补一条线；猜错一道题 = 删掉多余的分界。**两种错都只值一次点击。**

**为什么没有"待确认"状态？** 之前错题录进去不算确认就不进练习卷，

结果就是"录了但忘了确认 = 白录"。现在题目保存后即可选入练习卷，没有额外的入库确认步骤；本次打印哪些题由勾选决定。

## AI 题界理解（可选增强）

在 `api_key.txt` 放一个火山方舟 API Key（或设环境变量 `ARK_API_KEY`），切题时会额外让
豆包视觉模型指出每道题第一行的位置（语义理解），OCR 负责把这句话对准到像素上。
AI 成功时，题内的废线会被自动丢弃；AI 失败/未配置时自动退回纯几何 + OCR，不影响使用。

- 默认走 Agent Plan 网关 `/api/plan/v3` + `doubao-seed-2-1-pro`（已关深度思考，约 10s/页）；平台 key 或其他模型用环境变量 `ARK_MODEL` / `ARK_BASE_URL` 覆盖；
- **错题识别**：切题的同一次 AI 调用顺带判断每道题是否做错（看批改痕迹），疑似错题的卡片带红色「疑似错题」徽标——只是建议，勾不勾还是你说了算；没批改痕迹或看不出来时不标记；
- **知识点标注**：同一次调用顺带建议每道题的知识点（口径对齐输入框的联想词表），知识点空着的题直接填上、手填过的永不覆盖，判断不了不填；「AI 识别错题」时也会给空着的知识点补上；
- **去手写**：练习卷页面有「去手写」开关（默认开），铅笔答案和红笔批注按墨水深度自动移除、印刷体保留；对比度不对时自动放弃移除、原样打印。原图始终不动，只影响打印输出；
- 每页照片会发送到火山引擎云端（家庭作业照片，介意隐私可不配置）；
- 费用：flash 档模型，单页照片约千级 token，成本可忽略。

## 注意事项

- 数据库只存文件名（不存绝对路径），`questions.db` 和 `uploads/` 可随项目整体搬家；

  旧库的绝对路径会在首次启动时自动收敛成文件名。
- 删除某道题会一并删除它的照片；每个页组头部有「删除整页」，一键删掉该页全部题、所有切片和整页原图（有确认弹窗）；删一组里最后一道题时，也会连带删除共享的整页原图。
- 上传限制：jpg / png / webp / gif / heic，单张 ≤ 10MB。HEIC（iPhone 照片）上传时自动转成 JPG。

## 备份

`questions.db` 和 `uploads/` 是唯一不可再生的资产，建议定期打包：

```bash
python backup.py                # 输出到 backups/
python backup.py "D:/备份"      # 指定输出目录
```

数据库用 sqlite3 的在线备份 API 导出，服务开着也能拿到一致的快照。

zip 内就是项目结构（`questions.db` + `uploads/`），解压即可还原。

## 项目结构

```
app.py               FastAPI 路由与业务逻辑（上传、切题、遮挡、标注）
database.py          SQLAlchemy 引擎 / 会话 / 幂等加列迁移
models.py            Question 表结构
image_processing.py  页面放平 + 空白带分割线建议 + 按线切片
ocr_split.py         OCR 定位顶格题号行，与几何切线合并
ai_split.py          视觉大模型理解题界，OCR 负责像素定位
static/              前端（index.html 主界面、paper.html 练习卷、app.js、style.css）
backup.py            题库 + 照片打包快照
test_api.py          端到端 API 自测
test_app.py          文件生命周期 / 迁移 / 切题的单元测试
test_image_processing.py  图像处理单元测试
test_ocr_split.py    题号模式与切线合并的单元测试
test_ai_split.py     AI 题界理解与合并降级的单元测试
```

## 技术栈

FastAPI · SQLAlchemy · SQLite · OpenCV · Pillow · RapidOCR（CPU，题号定位） · 豆包视觉模型（可选，题界理解） · 原生 HTML/CSS/JS

> OCR 只在首次用到时加载模型（几秒）；没装 RapidOCR 也能跑，切题退回纯空白带检测。
