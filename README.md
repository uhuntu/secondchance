# 数学错题本

拍照上传 · 自动校正 · 按红叉切题 · 遮挡答案 · 生成练习卷

一个自用的错题采集工具：拍下孩子批改过的作业页，自动放平、按红色批改标记切出错题，
标注知识点后可一键生成一份把答案遮住的 A4 重练卷。

## 启动

```bash
pip install -r requirements.txt
python -m uvicorn app:app --port 8010
```

浏览器打开 <http://localhost:8010/>。

> 端口用 8010 而不是 8000：本机 8000 可能被梵想云（FanxiangCloud）自带的 nginx 占用。
> 首次启动会自动建表（`questions.db`）并给旧库补齐缺失字段，无需手动迁移。

## 使用流程

### 1. 拍错题
点 **📷 拍照 / 选择照片**，可以拍**整页作业**，再点 **保存错题**。

系统会自动放平页面、识别红色批改标记，并把每个标记切成一道候选错题。
完成后会提示：*"检测到 N 组明显红叉/圈叉，已切成 M 道候选错题"*；若没识别到红色批改，
则按整张照片保存为一道。同一张原卷切出的题会归为一组"一张原卷"。

### 2. 确认切割（校正并切割）
自动切题只是**候选**，需要在原卷分组上点 **校正并切割** 确认：

- 系统重新校正并给出放平预览。
- 若**没能**识别出纸张四角，会提示并进入 **手动放平原卷**：依次点击
  左上角 → 右上角 → 右下角 → 左下角，把页面拉成矩形。
- 在 **确认错题切割** 里，从每道题的**上边缘拖到下边缘**画出范围。
  画错就点 `错题 N ×` 标签删除，或 **清空范围**。
- 点 **确认保存** 后，这些切片才被标记为"已确认"。

### 3. 标注知识点
在卡片上点 **编辑**，填写 **知识点 / 错误原因**（有五年级上册知识点 + 常见错误原因的
输入联想）和 **备注**。

### 4. 遮挡答案（可选）
在**已确认**的切片上点 **遮挡答案**，拖框遮住孩子的答案或批改痕迹。
遮挡只作用于练习卷，不会改动原图。

### 5. 生成并打印练习卷
点 **📝 用错题生成练习卷**（打开 `/static/paper.html`），再点
**🖨️ 打印题目卷（给孩子）**。练习卷按知识点分组、套用遮挡，并按 A4 排版。

## 注意事项

- **只有"已确认切割"的题才会进练习卷**。刚上传、还没在"校正并切割"里确认的题不会出现；
  空练习卷也会提示先去确认。
- 遮挡坐标按图片宽高的千分比存储，重新打印到不同尺寸时依然对齐。
- 删除某道题会一并删除它的照片；删除一组里的最后一道题时，会连带删除共享的整页原图。
- 上传限制：jpg / png / webp / gif / heic，单张 ≤ 10MB。HEIC（iPhone 照片）上传时自动转成 JPG。

## 项目结构

```
app.py               FastAPI 路由与业务逻辑（增删改查、校正、切题、遮挡）
database.py          SQLAlchemy 引擎 / 会话 / 幂等加列迁移
models.py            Question 表结构
image_processing.py  页面放平（透视校正）+ 红色标记识别 + 切题
static/              前端（index.html 主界面、paper.html 练习卷、app.js、style.css）
test_api.py          端到端 API 自测
test_image_processing.py  图像处理单元测试
```

FastAPI · SQLAlchemy · SQLite · OpenCV · Pillow · 原生 HTML/CSS/JS
